# Usage

This section walks through the workflows you'll use day-to-day.

- [**Basic Usage**](./basic.md) — open the status window, create a new
  revision, edit a description, view a diff.
- [**Manipulating Commits**](./manipulating-commits.md) — abandon,
  reword, squash, and rewrite history from inside your editor.

For an exhaustive reference of what each buffer contains and the keys
it responds to, see the [Reference](../reference/index.md) chapter.
