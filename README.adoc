= Bad Juju

An LSP-powered, editor-agnostic front-end for
https://jj-vcs.github.com/jj/[Jujutsu].

== Overview

Bad Juju exposes Jujutsu VCS operations through the
https://microsoft.github.io/language-server-protocol/[Language Server Protocol],
so any LSP-capable editor can show jj status, conflict markers, and change
information inline.

== Repository Structure

----
server/          Rust LSP server (tower-lsp)
clients/
  vscode/        VS Code extension
docs/            Design documents
samples/         Example jj repos used for testing
----

== Prerequisites

* https://www.rust-lang.org/tools/install[Rust toolchain] (edition 2024)
* https://pnpm.io/installation[pnpm] 10+
* https://github.com/apenwarr/redo[redo] (apenwarr/redo — `brew install redo` on macOS)
* https://facebook.github.io/watchman/[Watchman] (used by the server for file watching)

== Building

[source,shell]
----
pnpm install
redo
----

== Testing

[source,shell]
----
redo test
----

== Development

To work on Bad Juju locally:

. Install the prerequisites listed above, including
  https://github.com/apenwarr/redo[redo] (`brew install redo` on macOS).
. Install JS dependencies and build the workspace:
+
[source,shell]
----
pnpm install
redo
----
. Install the `badjuju` server binary to your Cargo bin directory (`~/.cargo/bin`):
+
[source,shell]
----
redo server/install
----
+
The build configuration (`debug` or `release`) is read from the `configuration`
file at the repo root.
. Iterate on the VS Code extension:
.. Open the `clients/vscode` directory in VS Code (open it as the workspace root,
   not the repo root, so the launch config and `package.json` scripts resolve
   correctly).
.. Press kbd:[F5] to launch an Extension Development Host with the extension
   loaded. Open a Jujutsu repo inside the host window and run a command such as
   `Bad Juju: Open status window` from the command palette to exercise the
   extension.
.. Edits to `clients/vscode/src/` are picked up by rebuilding (`redo
   clients/vscode/all`) and restarting the Extension Development Host.
. Before committing, run the CI-equivalent check (formatting, clippy, tests,
  Biome):
+
[source,shell]
----
redo check
----
